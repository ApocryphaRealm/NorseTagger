# Changelog

## 1.0.0 - 2026-11-18 - working

### Added
- First release. It contains everything built and tested in 0.1.0, listed here and kept as history below:
- Tag rules in tags/*.ini: Tag = name | classes (parents included) | names | folders | field filters (Field:text, Tag:Name) | chance.
- Exports NT_HasTag and NT_Apply; NorseFilters.hpp answers Tag: filters for every framework (NorseDistributor first).
- Console nt.list, nt.tags, nt.reload, nt.apply; a summary per rule in NorseTagger.log.
- Ships its NorseManifest manifest (package/NorsePacks).
- main.dll carries a Windows version resource (file and product version 1.0.0, shown in its Properties > Details).
